    Folders → Labels

    Folders are now Gmail labels

    Gmail uses labels instead of folders. Your Outlook organization is preserved — but there's one mental shift to make.

    In Outlook: a folder is a place. An email lives in one folder. To organize, you move it.

    In Gmail: a label is a tag. An email can have multiple labels at once. Labels don't move emails — they tag them.

    Practical effect after migration: every old Outlook folder is now a Gmail label in your left sidebar. Click a label to see only emails tagged with it.

    Preserved. Subfolders become nested labels. So if you had Projects/Q1 2026 in Outlook, you'll see it in Gmail's sidebar as:

    Projects └─ Q1 2026 └─ Q4 2025 Clients └─ Acme Corp

    Click any nested label to see only those emails.

    Because labels don't move emails — they tag them. After migration, your old emails are tagged with their label AND still appear in your Inbox by default.

    Two ways to clean up:

    1. Archive: Select emails in the Inbox → click the archive button (down-arrow icon). They leave the Inbox but stay accessible under their label.
    2. Bulk archive a label: Open a label → select all → archive. Repeat per label, or set up a filter to do it automatically.

    Yes — and this is where Gmail starts to feel better than Outlook. Open any email, click the label icon at the top, and pick as many labels as you want. The same email shows up in all of them.

    Filters & rules

    Recreate your Outlook rules as filters

    Outlook rules don't migrate automatically. But Gmail filters are more powerful — recreate them in four clicks.

    1. In Gmail, click the search bar at the top
    2. Click the filter icon (sliders) on the right side of the search bar
    3. Set your criteria — From, Subject, Has the words, Has attachment, etc.
    4. Click Create filter
    5. Choose what should happen: Apply the label (pick label name), Skip the Inbox, Mark as read, etc.
    6. Click Create filter

    Outlook rule: "Move emails from boss@siphoxhealth.com to Important folder"

    Gmail filter equivalent:

    • From: boss@siphoxhealth.com
    • Apply label: Important
    • Optionally check: Skip the Inbox + Mark as read

    Outlook rule: "Move newsletters to Newsletters folder"

    Gmail filter equivalent:

    • Subject contains: Newsletter
    • Apply label: Newsletters
    • Check: Skip the Inbox

    Gmail's search operators are powerful. A few worth knowing:

    from:boss@siphoxhealth.com has:attachment after:2026/01/01
    • from: — sender address or name
    • to: — recipient
    • subject: — words in subject
    • has:attachment — emails with files
    • after:YYYY/MM/DD — date filter
    • label:invoices — within a specific label
    • is:unread — only unread

    Combine them. Search beats scrolling.

    Troubleshooting

    Something missing?

    Almost everything migrated. If you can't find something, it's usually somewhere unexpected — or your old Outlook still has it.

    1. Search Gmail. Try the sender's name, the subject, or a few words from the body. Gmail search is very good — it'll usually find it.
    2. Check labels. The email might be archived (out of Inbox) but still tagged with a label. Click the label in your sidebar.
    3. Check All Mail. Click "More" in the sidebar → "All Mail". This shows everything, archived and not.
    4. Check Outlook. Read access stays for several weeks. If it's there but not in Gmail, DM Eva or Pavel.

    Most files migrated. For any that didn't, here's the manual workaround:

    1. Go to onedrive.live.com (or your SharePoint site) and sign in with your @siphox.com account (still works for several weeks).
    2. Find the file. Right-click → Download.
    3. Go to drive.google.com (signed in as @siphoxhealth.com).
    4. Drag the downloaded file into your Drive, or click + New → File upload.

    For folders: download as ZIP, unzip locally, then upload to Drive.

    Calendar events should have migrated, including timezones. If something's off:

    1. Check the event timezone in Google Calendar (settings → general → time zone).
    2. If a recurring event has a wrong time, edit it in Google Calendar — set the correct timezone explicitly.
    3. If an event is completely missing, check old Outlook calendar (still accessible) and copy it over manually.
    4. For anything weird, DM Eva or Pavel — we can re-run a calendar delta sync if needed.

    Contact folders don't migrate as separate folders — instead, all contacts are merged into Google Contacts. Go to contacts.google.com and search there.

    If a contact is genuinely missing, you can export it from Outlook (right-click contact → "Save as" or in Outlook web: People → export) and import to Google Contacts (settings → import → CSV).
